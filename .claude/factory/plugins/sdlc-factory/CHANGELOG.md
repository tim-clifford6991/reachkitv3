# Doctrine changelog

One line per version; **migration** names the corpus rewrite that ships
with a grammar change (CLAUDE.md's three-part rule), and **none (stated)**
records — in the tree, not just in git — why a version rung ships without
one.

| Version | Change | Migration |
|---|---|---|
| 0.11.1 | Live-test fixes from the first 0.11.0 run on ReachKit v3: verbs are typed in the form that resolves under a namespaced plugin — `/sdlc-factory:<verb>` — with the rule stated once in §4's routing map ("Typing a verb"), the router card rendering that form, and every next-command line consistent with it; the console refuses a path that is not a project root (no `factory.config.json` there, or no declared type directory under its docs root) and names the nearest root that is one, so the docs directory can never again read as an empty, clean corpus; the gate is documented beside the checker with the `schema` line the header needs. This rung exists because `claude plugin update` compares version strings — fixes under an unchanged 0.11.0 never reach an installed host | none (stated) — a typing rule, a CLI guard and a doc; no field, status or file in any corpus changes meaning |
| 0.11.0 | Altitude (`docs/design/22-proposal-0.11.0-altitude.md`): rule 2.5 — a document that says what the code will say is a defect (2.2's general form); rule 2.6 — a work order is a slice, never a file, with the merge test 2.1 gives requirements, consolidated per wave as a merge never a discard; rule 2.3b — an assumption is discharged by the first stage that can observe it and never survives `done` (§3's sixth gate); §4's routing map — the only place routing is stated, rendered by the router hook (`/status` and `/blueprint` marked to fold at 0.12.0; `/implement` no longer chains `/validate`/`/regress` — `/factory` is their one caller); rule 4.4 — model tiers per agent (fable / opus / sonnet / haiku, in each agent's own `model:`; all four aliases verified honoured, no fallback). Four checker rules: `work-order-fanout`, `corpus-volume`, `assumption-budget`, `open-assumption-on-done` (error). Measured on the second live corpus: 253 WO / 46 approved REQ, 405 open rests-on, 14,824 words per approved requirement, at zero lines of code | `0.11.0-a-altitude-report` (report only — logs the ratios, writes nothing) |

Born from the first live project's owner: "I continue to be confused at what to trigger when" | none (stated) — a command and constitution text, no corpus rewrite |
