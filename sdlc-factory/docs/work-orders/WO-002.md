# WO-002 — Route-group skeleton, the root layout and font wiring

- Branch: wo/WO-002-route-skeleton
- Estimate: ≤1 day
- Preview: sdlc-factory/docs/design/previews/WO-002.html
- Signed-off: 2026-09-03

## Goal
Create the three-route-group skeleton BP-001 decision 2 fixes and the one root
document every ReachKit-addressed surface renders inside, carrying BP-018's
theme and fonts and no product copy of its own.

## Provenance of this file plan
**This repository holds no `src/`.** Every path below is NEW. Paths are anchored
to `structure.md`'s top-level table and to BP-001's `code:` globs; the plan is
provisional against a repo with no code.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `src/app/layout.tsx` | NEW | The root document. Sets `<html lang="en">`, applies BP-018's font CSS variables (WO-030) and the three-state theme attribute contract (WO-029), imports `src/ui/theme.css`. Renders `{children}` and nothing else — no navigation, no heading, no string. |
| `src/app/(public)/layout.tsx` | NEW | The public group's layout per BP-001 decision 2. Declares nothing about sessions; renders `{children}`. Exists so the group is the authorisation boundary rather than the route. |
| `src/app/(account)/layout.tsx` | NEW | The account group's layout. Asserts a session is present (the check itself is WO-003's middleware; this layout consumes the result) and renders `{children}`. Holds no shell chrome — BP-037 owns `src/app/(account)/app/layout.tsx`. |
| `src/app/(hosted)/layout.tsx` | — | **NOT this work order's.** BP-047 owns it by the more specific glob (`structure.md` rule 2). |
| `tests/app/layout.test.ts` | NEW | Asserts the root layout renders no literal string, imports `src/ui/theme.css`, and sets the font variables. |
| `tests/app/route-groups.test.ts` | NEW | Asserts the three route-group directories exist and that `(hosted)` carries no layout written by this work order. |

## Interfaces
Consumes (verbatim from BP-018 `## Public interface`):
```ts
export type Tone = 'ok' | 'warn' | 'bad' | 'neutral' | 'accent'
```
and BP-018's module boundary `src/ui/theme.css` (the three-state theming) and
`src/ui/fonts.ts`.

Exposes (verbatim from BP-001 `## Public interface`, the rows this work order
creates the container for):
```
Routes (public)
  GET  /                                landing: one field, one submit
  GET  /pricing                         the scanless price surface
Routes (account, session required)
  GET  /app                             redirects to Overview
```
This work order creates the groups those routes live in; the route files
themselves belong to their leaf nodes (BP-022, BP-037) and to work orders outside
this block.

## Steps
1. Create the three route-group directories.
2. Write `src/app/layout.tsx` importing `src/ui/theme.css` and `src/ui/fonts.ts`.
3. Write the `(public)` and `(account)` group layouts as pass-throughs.
4. Write the two tests; watch the "no literal string" test fail first by adding a
   string, then remove it (constitution §8, "Watch it fail first").

## Out of scope

  which are BP-019's copy registry, outside this block. Named here so they are
  not written without their copy.
