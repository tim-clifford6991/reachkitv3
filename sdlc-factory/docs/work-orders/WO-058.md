# WO-058 — `claimFreeScanSlot` — the single consumption point, in one transaction

- Branch: wo/WO-058-admission-claim
- Estimate: ≤1 day

## Goal
Make starting a free scan a single transaction that re-evaluates the same
admission order and inserts the `scans` row that *is* the in-flight record, so
two simultaneous submissions can only ever resolve to one scan.

## Interfaces

Consumes: WO-057's `Admission`, `NetworkKey`, and the six-step order it
implements; WO-051's `CanonicalDomain`; WO-056's `network_hash` and
`from_incomplete_rescan` columns; BP-002's `dbAdmin()`.

Exposes (verbatim from BP-023 `## Public interface`, `src/lib/scan/admission.ts`):

```ts
/** The consuming form. One transaction: re-evaluates the same order, inserts the
 *  `scans` row that *is* the in-flight record, and returns its id — so two
 *  simultaneous submissions cannot both pass. */
export function claimFreeScanSlot(a: {
  domain: CanonicalDomain; network: NetworkKey
  fromIncompleteRescan: boolean          // REQ-001 c14's once-only bound
}): Promise<{ claimed: true; scanId: string } | { claimed: false; refusal: Admission }>
```

## Steps
1. Write the failing suites first, the concurrency one included.
2. Extract WO-057's six steps into an internal, transaction-aware evaluator that
   both entry points call, so the order exists once in the file (rule 2.4).
3. Implement `claimFreeScanSlot` as one serialisable transaction: evaluate the
   order, and on `admit` insert the `scans` row and return its id. The in-flight
   bound is resolved by the `status = 'running'` predicate inside the same
   transaction — not by an application-held lock (BP-023's NFR budget).
4. Set `from_incomplete_rescan` from the parameter at insert time, and never
   anywhere else.
5. On refusal insert nothing: a refused scan produces no `scans` row at all
   (BP-023, "so it 'produces no report of its own'").
6. Confirm the fail-open handler from WO-057 still wraps the non-removal steps
   inside the transaction, and that a serialisation failure retries the
   transaction rather than admitting a second scan.
