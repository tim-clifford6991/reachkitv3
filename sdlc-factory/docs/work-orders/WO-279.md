# WO-279 — Generated text, the question and its search, and the surface sweep that proves nothing else gets through

- Branch: wo/WO-279-generated-text
- Estimate: ≤1 day

## Goal
Ship the only two ways model-produced text reaches a person — bound to the page it belongs to and to whether that page is written or merely proposed, and bound to the search it came from — and the path-glob suite over the surface tree that fails on a product sentence written as a string literal and on a `GeneratedColumn` value reaching a surface any other way.

## Consolidation (rule 2.6)
WO-044 is a test-only order whose whole subject is WO-043's two functions: its
goal names `renderGenerated` and `renderQuestion` and its flow gate is the proof
of WO-043's boundary. WO-043's `## Out of scope` hands that gate to WO-044 by
name. A boundary and the suite that proves it are one capability from interface
to test; splitting them is the horizontal cut along a layer rule 2.6 forbids.

### From WO-043

**Consumes:** `copy`, `CopyKey` from `src/lib/presentation/copy` (WO-041). The
labels `renderGenerated` returns are the `generated.page.written` and
`generated.page.proposed` keys WO-041 seeds; both are owner-owed.

**Exposes** (verbatim from BP-020 `## Public interface`):
```ts
// ── src/lib/presentation/generated/text.ts ───────────────────────────────────
/** Model output, wrapped at the point it is read out of storage. An unwrapped
 *  string is the product's own voice by construction; there is no widening
 *  cast in this module and no `GeneratedText` constructor that takes a literal. */
export interface GeneratedText { readonly source: 'model'; readonly text: string }
export function fromStored(column: GeneratedColumn, value: string): GeneratedText
export type GeneratedColumn =
  | 'drafts.body' | 'drafts.title' | 'drafts.slug' | 'drafts.description'
  | 'opportunities.proposed_title' | 'opportunities.proposed_slug'
  | 'questions.wording'

/** REQ-093 criterion 2. A written page carries all four fields; a proposed page
 *  carries a title and a slug and **has no description arm at all** — the
 *  requirement admits none, so none is representable. */
export type PageIdentity =
  | { state: 'written';  pageId: string;        title: GeneratedText; slug: GeneratedText
      body: GeneratedText; description?: GeneratedText }
  | { state: 'proposed'; opportunityId: string; title: GeneratedText; slug: GeneratedText }

/** The one sink for model text. It cannot be called without the identity of the
 *  page the text belongs to, and it returns the label and the text as one value,
 *  so a caller cannot render the text and drop the label. */
export function renderGenerated(
  field: GeneratedText,
  page: PageIdentity
): { label: string; text: string; proposed: boolean }

/** BP-019's declared helper, unchanged: the label alone, for a caller that
 *  already holds a `renderGenerated` result and needs its label separately. */
export function generatedLabel(a: { pageTitle: string; written: boolean }): { label: string }

// ── src/lib/presentation/generated/question.ts ───────────────────────────────
/** REQ-093 criterion 3. The wording of one of the twelve questions is admitted
 *  only on the condition that the search it was derived from is shown with it —
 *  so this returns an ordered pair the surface renders whole. There is no
 *  function that returns the wording alone. The *content* of `provenance` is
 *  REQ-006 criterion 9's and is built by that requirement's node; this node
 *  owns only that the pair cannot be split. */
export function renderQuestion(q: {
  wording: GeneratedText
  provenance: string          // supplied by REQ-006's node, already rendered
}): readonly [{ role: 'question'; text: string }, { role: 'provenance'; text: string }]
```

## Steps

**WO-043's steps** (renumbered; order within the block unchanged):

1. Create `text.ts`. Declare `GeneratedText` with both fields `readonly` and
   `source` fixed to the literal `'model'`. Implement `fromStored(column, value)`
   returning `Object.freeze({ source: 'model', text: value })`. Declare
   `GeneratedColumn` as the seven-member union above, exactly. Do not export any
   other constructor, factory, cast helper or `as GeneratedText` expression.
2. Declare `PageIdentity` as the two-arm union above, exactly. The `proposed` arm
   has **no** `description` field and no `body` field — BP-020 `## Error & edge
   behavior`, seventh bullet.
3. Implement `renderGenerated(field, page)`: `proposed` is
   `page.state === 'proposed'`; `label` is `copy('generated.page.proposed', {
   pageTitle: page.title.text })` on the proposed arm and
   `copy('generated.page.written', { pageTitle: page.title.text })` on the
   written arm; `text` is `field.text` **untruncated** — the decision to truncate
   belongs to the surface (BP-020 `## Error & edge behavior`, tenth bullet). The
   three fields are returned as one value; there is no overload returning `text`
   alone.
4. Implement `generatedLabel(a)` as the label-only helper, delegating to the same
   `copy()` calls step 3 uses. One label producer, not two (rule 7.1).
5. Create `question.ts`. `renderQuestion` returns
   `[{ role: 'question', text: q.wording.text }, { role: 'provenance', text: q.provenance }] as const`.
   The file exports exactly one function. It does not build, alter or validate
   the content of `provenance` — that is REQ-006 criterion 9's node's.
6. Create `index.ts` re-exporting exactly the symbols above.
7. Write both test files. Watch each fail before its source file exists.

**WO-044's steps** (renumbered; order within the block unchanged):

8. Create `surface-tree.ts`. Walk the four globs from a supplied root using
   `node:fs`'s recursive directory read; return `{ files: string[]; perGlob:
   Record<string, number> }`. Skip nothing silently — a directory that does not
   exist yet contributes `0` and is reported as `0`, never omitted (rule 5.5).
9. Create `allowlist.ts` and `budget.ts`.
10. Create the fixture tree under `tests/presentation/copy/__fixtures__/surfaces/`
   mirroring the four glob shapes, with the six files listed in the file plan.
11. Write `string-literal-sweep.test.ts`. Parse each file with
   `ts.createSourceFile` and walk the AST: flag `JsxText` with non-whitespace
   content, a `StringLiteral` or `NoSubstitutionTemplateLiteral` in a JSX
   attribute whose name is text-bearing, and a string literal in a mail template
   body. Compare against `allowlist.ts`. Two describes: one over the fixture tree
   (must flag exactly the known violations, by file and position, and must not
   flag the clean files or the allow-listed attribute) and one over the real
   surface globs (must flag nothing). Emit the coverage statement:
   files walked per glob, literals inspected, violations found, allow-list hits.
12. Write `flow-gate.test.ts`. For each enumerated file, flag any identifier or
   property access naming one of the seven `GeneratedColumn` strings, or a value
   typed `GeneratedText`, that reaches a JSX text position or a text-bearing prop
   without passing through a call to `renderGenerated` or `renderQuestion` in the
   same expression. Same two describes over fixture tree and real tree; same
   coverage statement.
13. Assert the wall clock of each describe against `COPY_SWEEP_BUDGET_MS`.

## Out of scope
- The content of a question's provenance line (REQ-006 criterion 9's node).
- The draft-under-review label — REQ-045's, and REQ-093's own non-goal.
- Where a label sits and how generated content is styled or badged — BP-018's.
- The surface-wide flow gate that proves no `GeneratedColumn` value reaches a
- Truncating long model text in a surface slot: `renderGenerated` returns `text`
  untruncated by design.
- Any CI configuration, branch protection or pre-commit hook. ADR-010 point 6 and
  constitution rule 3.3: these suites are recorded, not enforced, and creating
  the enforcement is a platform decision this WO does not make.
- An ESLint rule — ADR-010 alternative 2 rejects it as the gate; it remains
  available later as ergonomics derived from `allowlist.ts`.
- The cold-start route sweep (WO-047) and the stopped-state sweep (WO-050).
- Type-level enforcement at the `src/ui/` boundary — ADR-010 alternative 3
  rejects it on `structure.md` rule 6 grounds.
