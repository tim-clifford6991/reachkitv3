# WO-077 — Domain normalisation: registrableDomain, isPlatformDomain, isOwnDomain

- Branch: wo/WO-077-domain-normalisation
- Estimate: ≤1 day

## Goal
Implement `src/lib/market/rivals/domains.ts` — the product's one answer to "what domain is
this", "is it a platform" and "is it the customer's own", so a customer's own hosted page
can never become their own rival.

**Risk: normal.** Three pure string functions with no I/O, no clock, no spend and no write: they move no money, read no session, call back to no third party and publish nothing. The customer-visible consequence of a wrong answer here — a customer's own hosted page shown as their own rival — lands in WO-078's and WO-080's outputs, and those are where it is mutation-tested (doctrine 0.13.2, rule 2b).

## Interfaces
**Consumes**: `PLATFORM_DOMAINS` from `src/lib/config/constants.ts` (BP-005) — BP-026's
`## Error & edge behavior`: "the list is BP-005's closed `PLATFORM_DOMAINS` and a domain
absent from it is a product domain by default".

**Exposes** — copied exactly from BP-026's `## Public interface`:

```ts
// src/lib/market/rivals/domains.ts
export function registrableDomain(hostOrUrl: string): string | null   // eTLD+1, lower-cased
export function isPlatformDomain(host: string): boolean               // BP-005's closed list
export function isOwnDomain(host: string, ownDomain: string): boolean // www. and content. included
```

## Steps
1. `registrableDomain`: accept a bare host or a full URL. Lower-case, strip a trailing dot,
   strip userinfo/port/path/query, and reduce to eTLD+1 using a public-suffix table shipped
   with the dependency (do not hand-roll a two-label rule — `example.co.uk` must reduce to
   `example.co.uk`, not `co.uk`). Anything that is not a parseable host returns `null`.
   An IP literal returns `null`.
2. `isPlatformDomain`: `registrableDomain` then membership in `PLATFORM_DOMAINS`. A domain
   absent from the list is **not** a platform — the open-world side is the rival side.
3. `isOwnDomain(host, ownDomain)`: true when `registrableDomain(host) ===
   registrableDomain(ownDomain)`. That single rule already covers `www.` and the `content.`
   publishing subdomain, both of which reduce to the same eTLD+1; assert both explicitly
   rather than special-casing either prefix.
4. All three are pure and total — no network, no DNS, no clock, no throw. A malformed input
   returns `null`/`false`.
5. Write the tests; watch each fail first.
