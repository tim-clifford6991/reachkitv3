# WO-023 — DataForSEO transport, credentials and the never-list enforced by absence

- Branch: wo/WO-023-dataforseo-transport
- Estimate: ≤1 day

## Goal
Build the one typed boundary to DataForSEO — transport, credentials, error
mapping and the shape every endpoint function is written to — so that a call the
product may not make has no function to call.

**Risk: high — seams: money, and data leaving the system.** This file is the only place the DataForSEO credential is read and the only place an outbound call to a paid third party is made, and `00-project.md`'s cost envelope is enforced in exactly this kind of seam. Its central promise is negative — the never-list is enforced by a function's *absence*, so a call the product may not make has nothing to call — and a test that survives adding an endpoint function leaves that promise vacuous while every added call bills. Mutation-tested (doctrine 0.13.2, rule 2b).

## Provenance of this file plan
**This repository holds no `src/`.** Every path is NEW, anchored to
`structure.md`'s row for `src/lib/vendors/**` and BP-008's `code:` globs.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `src/lib/vendors/dataforseo/transport.ts` | NEW | The one request builder. Credentials from `env` (`DATAFORSEO_LOGIN`, `DATAFORSEO_PASSWORD`), never appearing in a log, a payload or an error message. | `tests/vendors/never-list.test.ts` | NEW | The tests below. |

## Interfaces
Exposes (verbatim from BP-008 `## Public interface`, the surface this work order
fixes and the next two fill):
```ts
// Every call takes the CostContext; none can be made outside one.
export function rankedKeywords(c: CostContext, a: { domain: string; rows: 50|100|300 }): Promise<Measured<RankedRow[]>>
export function keywordSuggestions(c: CostContext, a: { seed: string; rows: 50 }): Promise<Measured<SuggestionRow[]>>
export function competitorsDomain(c: CostContext, a: { domain: string }): Promise<Measured<CompetitorRow[]>>
export function serpOrganic(c: CostContext, a: { query: string; mode: 'live'|'std' }): Promise<Measured<SerpResult>>
  // SerpResult carries organic top-10 AND the ai_overview item with its
  // reference domains — the free AI matrix rides here at 0c extra
export function aiMode(c: CostContext, a: { query: string; mode: 'live'|'std' }): Promise<Measured<AiAnswer>>       // paid battery only
export function llmScraper(c: CostContext, a: { query: string; mode: 'std' }): Promise<Measured<AiAnswer>>          // paid battery only

// Every call is fixed to SERP_LOCATION (Google US / en) and depth 10.
```
Consumes: `CostContext` (BP-007), `Measured<T>` (BP-010, type-only), `env` and
`PRICE_BOOK`/`SERP_LOCATION` (BP-005).

## Steps
1. Write `types.ts` as product types.
2. Write `transport.ts` with credentials, location and depth fixed.
3. Write `index.ts` declaring the six exports.
4. Write the never-list test; watch it fail first by adding a generic
   `dataforseo(endpoint, params)` export.
