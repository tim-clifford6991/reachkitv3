# WO-026 — The llm() seam — model tiers, schema-parsed output, per-call cost logging

- Branch: wo/WO-026-llm-seam
- Estimate: ≤1 day

## Goal
Make every model call go through one function with a declared tier, a declared
cost and a typed output that is parsed or the call failed.

**Risk: high — seams: money, and data leaving the system.** Every model call the product ever makes goes through this one function: its tier, its logged cost against the spend envelope, and the customer's own page text crossing to a third party. A cost-logging test that survives deletion of the logging spends silently, and a schema-parse test that survives deletion lets an unparsed payload through as if it were typed. Mutation-tested (doctrine 0.13.2, rule 2b).

## Provenance of this file plan
**This repository holds no `src/`.** Every path is NEW, anchored to
`structure.md`'s row for `src/lib/llm/**` and BP-009's `code:` globs.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `src/lib/llm/tiers.ts` | NEW | The two tiers — `nano` and `haiku` — each bound to its model id and its per-call cost, read from `env` (`ANTHROPIC_API_KEY`, `NANO_API_KEY`) and `constants.ts`. `BUILD.md` §1: "**Anthropic Haiku 4.5** (prose) + a nano-class model (scaffolding)". No third tier. |
| `src/lib/llm/index.ts` | NEW | `llm()`. Runs inside the caller's `CostContext` via `recordFetch`, with the **call site as the ledger row's `source`**. Parses the response against the supplied `ZodType<T>`; a response that does not parse returns `unmeasured` with reason `unparseable` and is retried at most once inside the caller's budget, never silently coerced. Model unavailability returns `unmeasured`; it never throws. |
| `tests/llm/seam.test.ts` | NEW | The tests below. |

## Interfaces
Exposes (verbatim from BP-009 `## Public interface`):
```ts
export function llm<T>(c: CostContext, call: {
  site: LlmCallSite
  input: unknown
  schema: ZodType<T>          // output is parsed or the call failed
  tier: 'nano' | 'haiku'
}): Promise<Measured<T>>
```
Consumes (verbatim from BP-007 `## Public interface`): `CostContext` and its
`recordFetch`. Consumes `LlmCallSite` from WO-027 and `Measured<T>` from BP-010.

## Steps
1. Write `tiers.ts`.
2. Write `llm()` over `recordFetch`, with the call site as `source`.
3. Add the schema parse and the single retry.
4. Write the tests; watch the "unparseable is never coerced" test fail first by
   falling back to the raw string.
