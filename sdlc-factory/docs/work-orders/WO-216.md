# WO-216 — The telling — what the customer is told, when the pair changes, and the one mail that cannot be suppressed

- Branch: wo/WO-216-telling
- Estimate: ≤1 day

## Goal
Ship `tellingFor`, `toldCurrentPair`, `recordTold` and `isUnsuppressible` — the occasion, the payload contract and the record of what was said — so a page whose telling is owed is held rather than published.

## File plan

> This repository carries no `src/`, no `tests/`, no `supabase/` and no
> `package.json` (verified 2026-08-31). **Every path below is NEW** — none was
> verified to exist, because none can. Placement is anchored to
> `sdlc-factory/docs/registry/structure.md` and to this work order's blueprint
> `code:` globs, and is provisional against a repo with no code: if the
> implementer finds a file already present at one of these paths, they stop and
> log `failed` naming the drift rather than merging into it.

| File | New/Modify | Change |
|---|---|---|
| `src/lib/publish/publishable/telling.ts` | NEW | The `Telling` union, `GoverningPair`, `tellingFor`, `toldCurrentPair`, `recordTold`, `isUnsuppressible`. `toldCurrentPair` compares the `GoverningPair` in force against `drafts.told.pair` and returns `told:false` with the telling now owed on any difference that changes whether or when the page publishes, distinguishing `never_told` from `pair_changed`. `isUnsuppressible` is true for `kind:'no_interval'` and for nothing else. `recordTold` writes `{pair, kind, publishesAt, sentAt}` to `drafts.told`. **This module writes no mail and no sentence** — it returns the occasion, the copy key and the values the key interpolates. |
| `tests/publish/publishable/telling.test.ts` | NEW | The three `Telling` kinds are produced for the three pairs; `isUnsuppressible` is true for `no_interval` alone; a pair change of each of the four fields re-opens the obligation and a change that alters neither whether nor when does not; `recordTold` then closes it; the zero-window telling carries `suppressible: false, unsubscribeLink: false`; **no test fixture contains a sentence** — every assertion is on a `CopyKey`. |

## Interfaces

**Consumes**

- `DraftView` — WO-206.
- `becomesPublishable` — WO-215 (for `publishesAt` on the interval and zero-window kinds).
- `PublishingSettings`, `Mode` — BP-057, `src/lib/publish/settings/settings.ts` (WO-218); `GoverningPair` is `{mode, vetoHours, publishTime, timezone}`.
- `sendEmail()` and `MAIL_KINDS` — BP-016, `src/lib/mail/`. **Called by the sender, not by this module**: this module returns the occasion and payload only.
- `copy()` and the `CopyKey` registry — BP-019, `src/lib/presentation/`. The keys `mail.draftReady.autopilotWindow`, `mail.draftReady.autopilotZero` and `mail.draftReady.copilot` are named here; the sentences are the owner's (REQ-093, constitution §1).

**Exposes** — copied exactly from BP-046's `## Public interface`:

```ts
// src/lib/publish/publishable/telling.ts
export type Telling =
  | { kind: 'interval';     publishesAt: Date; stopAction: VetoLink; copy: 'mail.draftReady.autopilotWindow' }
  | { kind: 'no_interval';  publishesAt: Date;                        copy: 'mail.draftReady.autopilotZero' }
  | { kind: 'approval_only';                                          copy: 'mail.draftReady.copilot' }

export interface GoverningPair {          // the pair REQ-057 criterion 8 tracks
  mode: 'autopilot' | 'copilot'
  vetoHours: number                       // 0..168, BP-057
  publishTime: string                     // 'HH:mm', in `timezone`
  timezone: string                        // IANA
}

export function tellingFor(d: DraftView): Telling
export function toldCurrentPair(d: DraftView):
  | { told: true }
  | { told: false; owed: Telling; because: 'never_told' | 'pair_changed' }
export function recordTold(draftId: string, t: Telling, pair: GoverningPair): Promise<void>

/** True only for `kind: 'no_interval'`: this telling is the whole of the telling. */
export function isUnsuppressible(t: Telling): boolean
```

**The zero-window telling is sent before the claim commits** (BP-046 decision
2): send, then `recordTold`, then claim. A send failure fails the `customer_told`
guard and holds the page rather than publishing it untold. That ordering is
enforced in WO-212's claim; this work order supplies the predicate the guard
reads and the payload the sender needs.

**No unsubscribe link on the zero-window mail** (BP-046 decision 3, REQ-057
criterion 7's own words: "because no link would stop it"). Adding one will look
like a compliance fix and is not one. The `sendEmail` call carries
`suppressible: false, unsubscribeLink: false`.

## Steps
1. Create `publishable/telling.ts` with the block above verbatim.
2. Derive `Telling` from the `GoverningPair` alone: autopilot with `vetoHours > 0` ⇒ `interval`; autopilot with `vetoHours === 0` ⇒ `no_interval`; copilot at any window ⇒ `approval_only`.
3. Implement `toldCurrentPair` as one comparison against `drafts.told.pair`. A difference that changes whether or when the page publishes returns `told:false`; a difference that changes neither does not.
4. Implement `recordTold` as one write of `{pair, kind, publishesAt, sentAt}`.
5. Name the three copy keys and write **no string**. Assert in test that no fixture in this module contains a sentence.
6. Write the pair-change tests first and watch "a page whose telling is owed is held" fail against an implementation that publishes and then tells (constitution §8).
